# AI Dev Platform

Платформа для AI-first разработки, которая связывает сотрудников, проекты, GitHub-репозитории, агентов и рабочие инструкции.

## Идея

Разработчик подключается к разрешённому проекту, а его агент получает те же права и нужный проектный контекст. Платформа помогает подготовить рабочее окружение и проверить доступ к репозиториям, сохраняя контроль компании над доступами и данными.

## Первая версия

- Учётные записи сотрудников и вход по приглашению.
- Создание проектов и подключение одного или нескольких GitHub-репозиториев.
- Хранение инструкций проекта и подключение одного выбранного командой агента.
- Доступ агента только к тем проектам и репозиториям, которые разрешены сотруднику.
- Отзыв доступа сотрудника и его агента.

Интеграции проектируются как отдельная часть платформы. Первой будет GitHub; другие сервисы могут подключаться позже.

## Дальнейшее развитие

Возможные направления — команды и роли, общие инструменты и скиллы, корпоративный агент, интеграции с трекерами задач, запуск агентов в изолированной облачной среде, проверки качества, релизы и эксплуатация. Их приоритеты будут определяться по результатам первой версии.
